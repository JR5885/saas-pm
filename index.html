全團隊對齊中

▸ 非同步發送：將 LINE 推播與通知拆移至背景排程，保障主要預約 API 速度。

▸ 灰度保護 (Canary)：透過功能開關 (Feature Flag) 控制開放範圍，出問題 1 秒切回。
